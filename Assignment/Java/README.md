# Strategy Pattern for Multimodal Phishing Detection under Non-Random Information Loss

Khaled Ibrahim Hamed Alamri — 4714389 — MSCS811

This complete Windows VS Code project adapts the text-acquisition problem and fictional pilot fixtures from my master’s research on multimodal phishing detection under non-random information loss. It demonstrates Java software design, not a trained phishing classifier.

## Open and run

1. Extract the whole ZIP. In VS Code open `ThesisStrategy.code-workspace` (or File > Open Folder and select this folder).
2. Java 8+ and Node.js with npm must be available on PATH. For Java editing/debugging, install the recommended **Extension Pack for Java** and configure a compatible JDK if prompted. The included compiler lets the tasks build without a separate javac installation.
3. Terminal > Run Task > **Setup OCR dependencies** (first use only). This installs pinned Tesseract.js using the included npm lockfile.
4. Terminal > Run Task > **Run demo**. Output appears in the integrated terminal.
5. Terminal > Run Task > **Run 8 tests** to verify behavior.
